## Getting Started

### Prerequisites

- Python 3.x installed on your machine

### Running the programs

Clone the repo:

```bash
git clone https://github.com/sanjayvarma-gif/python-problems.git
cd python-problems
```

Run the file:

```bash
python programs.py
```

> **Note:** All 20 programs currently run sequentially in one file. Each program that needs input will prompt for values via `input()` in the order they appear (e.g., Program 1 first asks for name, then age, then height, before moving on to Program 2, and so on). Enter values one at a time as prompted.

## Topics Covered

- Variables and data types (`int`, `float`, `str`)
- Taking input from the user and type conversion
- Arithmetic operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`)
- Comparison operators (`>`, `==`)
- Logical operators (`and`, `or`, `not`)
- Augmented assignment (`+=` style logic)
- Swapping variables (multiple techniques, including XOR and tuple unpacking)
- Simple real-world formulas (simple interest, temperature conversion, rectangle area)
